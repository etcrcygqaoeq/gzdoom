## 🕹️ Overview

GZDoom is the leading Doom source port with an OpenGL and Vulkan renderer, ZScript modding language, and compatibility with thousands of community WAD files.

Whether you're a newcomer or a veteran, GZDoom provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Vulkan Renderer** | Modern GPU rendering with dynamic lights and material shaders |
| **ZScript** | Powerful object-oriented scripting for total conversion mods |
| **WAD Compatibility** | Plays Doom, Doom II, Heretic, Hexen, and Strife content |
| **Mod Database** | Browse and launch idgames and other archives directly |
